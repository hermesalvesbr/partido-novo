# Eu voto em Renan Bihum 3037

Arte 1080x1920 (stories/reels) refeita em HTML a partir da arte do Canva.

- `index.html`: a arte. Abra no navegador; `index.html?export` mostra em 1:1.
- `renan-bihum-3037.png`: arte exportada.
- `renan-amarela.webp`: foto real do Renan (IMG_1645, evento NOVO 30, Drive).
  A polo azul-marinho foi recolorida para amarelo por ajuste de cor
  (OpenCV, mapeando a luminosidade original) e o fundo recortado com GrabCut.
  Nenhuma ferramenta de IA generativa foi usada; rosto e adesivos estão intactos.
- `paisagem.svg`: paisagem do Sertão do Araripe (céu, Chapada, caatinga),
  desfocada atrás dele. Para usar uma foto real, troque `--paisagem` no CSS.
